# ゴールド相場情報表示ツール

金価格、ETF 1540、為替レートを一元表示するWebアプリケーションです。

## 特徴

- **自動データ補完**: 起動時に自動的に最新データを取得
- **オフラインファースト**: ローカルデータを優先し、ネットワーク依存を最小化
- **シンプルな操作**: ブラウザで開くだけで動作

## クイックスタート

```bash
# 初回データ取得（必須）
make update

# ブラウザで表示
open index.html
```

## 使い方

1. **初回セットアップ**: `make update`でベースデータを取得
2. **ブラウザで開く**: index.htmlを開くと自動的に最新データを補完
3. **手動更新**: 必要に応じて「最新データ取得」ボタンで強制更新

## データソース

- **Stooq.pl**: 過去30日分の日次データ（ベースデータ）
  - 金スポット価格（XAUUSD）
  - ETF 1540（東京証券取引所）
  - USD/JPY為替レート

- **Yahoo Finance**: ブラウザ経由で最新データを自動補完
  - CORSプロキシ（corsproxy.io）経由
  - LocalStorageに保存して永続化

## 表示内容

### 統計情報
- 最新値、平均値、最高値、最安値、変動率を表示
- スポット価格、ETF 1540、USD/JPYの3種類

### グラフ
- 5日、1週間、30日の期間選択
- 複数Y軸（左：USD価格、右：円価格）
- ETFがない日（土日祝）も含めて全データ表示

### データテーブル
- 過去30日間のデータ
- ETFがある営業日のみ表示

## コマンド一覧

```bash
make update       # データ更新（fetch → convert）
make fetch        # Stooqからデータ取得
make convert      # CSV → JSON/JS変換
make check        # データファイル確認
make clean        # データファイル削除
make clean-cache  # キャッシュ削除
make help         # ヘルプ表示
```

## 技術仕様

- **データ更新**: 起動から2秒後に自動実行
- **レート制限**: 自動更新は1時間に1回
- **手動更新**: レート制限を無視して即時取得
- **データ永続化**: LocalStorageで補完データを保存
- **エラーハンドリング**: ステータスラインにエラー表示

## トラブルシューティング

### データが表示されない
```bash
make clean
make update
```

### 最新データが反映されない
- ブラウザで「最新データ取得」ボタンをクリック
- LocalStorageをクリアして再読み込み

### CORSエラー
- corsproxy.ioが一時的に利用不可の可能性
- 時間をおいて再試行

## 注意事項

- 表示データは参考値です
- 実際の取引には各証券会社の最新情報をご確認ください
- APIは個人利用のみ
